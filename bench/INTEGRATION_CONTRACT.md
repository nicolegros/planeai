# Benchmark Integration Contract

Shared contract between the PlaneAI benchmark harness and the Iced/alacritty Rust spike.

## Boundary

The two implementations communicate only through:

1. **Raw ANSI fixture files** as input.
2. **CLI arguments** for replay settings.
3. **JSONL metrics files** as output.
4. **Optional visible-text snapshot files** for correctness.

Do not depend on the other implementation's source code.
Do not import the benchmark harness into the Rust spike.
Do not import the Rust spike into the Tauri app.
Do not invent separate metrics schemas.

---

## Fixture Format

- Raw terminal byte streams, no JSON envelope.
- Extension: `.ansi`
- Preserves: ANSI escape sequences, carriage returns, colors, cursor movement, partial chunks.
- Generated by `bench/generate-fixtures.py` or captured from a real session.

---

## Iced Spike CLI Interface

### Required command shape

```bash
planeai-iced-spike \
  --replay bench/fixtures/mixed-agent-like.ansi \
  --cols 120 \
  --rows 40 \
  --chunk-size 16384 \
  --chunk-interval-ms 4 \
  --metrics bench/results/iced-alacritty_mixed-agent-like_120x40_16k_4ms_run1.jsonl \
  --backend iced-alacritty \
  --exit-when-done
```

### Required flags

| Flag | Type | Description |
|------|------|-------------|
| `--replay` | path | Input .ansi fixture file |
| `--cols` | int | Terminal columns |
| `--rows` | int | Terminal rows |
| `--chunk-size` | int | Bytes per chunk |
| `--chunk-interval-ms` | int | Delay between chunks (0 = maxspeed) |
| `--metrics` | path | Output JSONL metrics file |
| `--backend` | string | Must be `iced-alacritty` |
| `--exit-when-done` | flag | Exit process after replay completes |

### Optional flags

| Flag | Type | Description |
|------|------|-------------|
| `--snapshot` | path | Write final visible terminal text |
| `--font-size` | int | Font size for rendering |
| `--scrollback-lines` | int | Scrollback buffer size |
| `--max-runtime-ms` | int | Safety timeout |
| `--headless` | flag | Run without window if supported |
| `--warmup-ms` | int | Warmup period before measuring |

The spike must create the metrics parent directory if it doesn't exist.

### Binary resolution by the harness

1. `PLANEAI_ICED_SPIKE_BIN=/path/to/planeai-iced-spike` (preferred — avoids rebuild)
2. `--iced-binary` flag on `run-benchmark.py`
3. Auto-detect: `planeai-iced-spike` on PATH or in `target/release/`

## JSONL Metrics Schema

### Common fields (all events)

```json
{
  "schema_version": 1,
  "timestamp_ms": 123.45,
  "event_type": "...",
  "backend": "iced-alacritty",
  "fixture": "mixed-agent-like.ansi",
  "cols": 120,
  "rows": 40,
  "chunk_size": 16384,
  "chunk_interval_ms": 4,
  "bytes_total": 2097152
}
```

### Backend-specific per-event fields

| Field | tauri-xterm | iced-alacritty | Description |
|-------|-------------|----------------|-------------|
| `write_latency_ms` | ✓ | null | xterm term.write callback latency |
| `parse_time_ms` | null | ✓ | ANSI parsing / grid update time |
| `frame_delta_ms` | ✓ | ✓ | Time between visual frames |
| `render_work_ms` | null | ✓ | Time spent doing GPU/rendering work |
| `rss_mb` | null | ✓ | Process RSS memory |
| `js_heap_mb` | ✓ | null | JavaScript heap usage |
| `queue_depth_bytes` | ✓ | ✓ | Bytes waiting to be processed |
| `bytes_since_last_event` | ✓ | ✓ | Bytes in this chunk |

### Required event types

**iced-alacritty:**
`replay_start`, `chunk_sent`, `chunk_received`, `parse_batch` (or `parse_start`/`parse_done`), `render_frame` (or `render_start`/`render_done`), `frame_sample`, `backlog_sample`, `replay_done`, `summary`

**tauri-xterm:**
`replay_start`, `chunk_sent`, `frontend_chunk_received`, `xterm_write_start`, `xterm_write_done`, `raf_frame`, `backlog_sample`, `replay_done`, `summary`

### Replay mode

- `chunk_interval_ms == 0` → `"maxspeed"`
- `chunk_interval_ms > 0` → `"realtime"`

### Null fields

Fields that don't apply to a backend should be explicitly `null`, not omitted.

- tauri-xterm: `parse_time_ms`, `render_work_ms`, `rss_mb` → null
- iced-alacritty: `write_latency_ms`, `js_heap_mb` → null

## Pacing Correctness

For realtime replay:

```
expected_min_replay_time_ms = ceil(total_bytes / chunk_size) * chunk_interval_ms
```

The harness warns if `wall_time_ms < expected_min_replay_time_ms * 0.8`.

This prevents fake high MB/s caused by ignoring the chunk interval.

## Result Naming Convention

```
bench/results/{backend}_{fixture_stem}_{cols}x{rows}_{chunk_kb}k_{interval_ms}ms_run{n}.jsonl
```

Examples:
```
bench/results/tauri-xterm_mixed-agent-like_120x40_16k_4ms_run1.jsonl
bench/results/iced-alacritty_mixed-agent-like_120x40_16k_4ms_run1.jsonl
```

Snapshots use `.txt` extension at the same path:
```
bench/results/iced-alacritty_mixed-agent-like_120x40_16k_4ms_run1.txt
```

---

## Correctness Snapshots

If `--snapshot <path>` is provided:
- Write the final visible terminal text (rows × cols) to that path.
- Plain text, no color codes.
- One line per terminal row.
- Used for rough correctness verification, not pixel-perfect comparison.

---

## Metric Naming Rules

| Metric | Meaning | Backend |
|--------|---------|---------|
| `write_latency_ms` | xterm `term.write` call → callback | tauri-xterm only |
| `parse_time_ms` | ANSI bytes → terminal state update | iced-alacritty only |
| `frame_delta_ms` | Time between visual frames | both |
| `render_work_ms` | Time spent in render pass | iced-alacritty only |

**Do not** compare `write_latency_ms` directly against `parse_time_ms` — they measure different things.

**Do not** compare Tauri RAF frame delta against Iced render work — `frame_delta_ms` is comparable between backends; `render_work_ms` is not.

## Smoke Test

```bash
# 1. Generate fixture
python bench/generate-fixtures.py --size medium --fixtures mixed-agent-like

# 2. Run tauri-xterm
PLANEAI_BENCH_REPLAY=$(pwd)/bench/fixtures/mixed-agent-like.ansi \
PLANEAI_BENCH_METRICS=$(pwd)/bench/results/tauri-xterm_mixed-agent-like_120x40_16k_4ms_run1.jsonl \
PLANEAI_BENCH_EXIT=1 \
./src-tauri/target/release/planeai

# 3. Run iced-alacritty
planeai-iced-spike \
  --replay bench/fixtures/mixed-agent-like.ansi \
  --cols 120 --rows 40 --chunk-size 16384 --chunk-interval-ms 4 \
  --metrics bench/results/iced-alacritty_mixed-agent-like_120x40_16k_4ms_run1.jsonl \
  --backend iced-alacritty --exit-when-done

# 4. Verify both have summary events
tail -1 bench/results/tauri-xterm_mixed-agent-like_120x40_16k_4ms_run1.jsonl | python -c "import sys,json; assert json.load(sys.stdin)['event_type']=='summary'"
tail -1 bench/results/iced-alacritty_mixed-agent-like_120x40_16k_4ms_run1.jsonl | python -c "import sys,json; assert json.load(sys.stdin)['event_type']=='summary'"

# 5. Summarize together
python bench/summarize-metrics.py bench/results/*.jsonl
```
